REST API 接口

GET /api/query/flight?flight=CA981 按航班号查询
GET /api/search/route?from=PVG&to=JFK&date=2026-04-01 按航线搜索（含价格）
GET /api/airports?q=上海 机场模糊搜索
GET /api/airports/resolve?name=浦东 机场解析（中文/英文/IATA）
GET /api/config 读取配置
POST /api/config 保存配置
GET /api/info 服务器信息
