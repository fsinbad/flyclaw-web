🚀 一、快速开始

FlyClaw 网页服务启动后，在浏览器中打开即可使用。默认地址为 http://127.0.0.1:8080。

启动 Web 服务器

# 默认端口 8080，监听所有网络接口 python3 server.py # 自定义端口 python3 server.py --port 9090 # 仅本地访问 python3 server.py --host 127.0.0.1 --port 8080

启动后在浏览器访问 http://127.0.0.1:8080 即可看到图形界面。

💡 提示：FlyClaw 无需注册任何账号或提供 API Key，开箱即用。

✈️ 二、按航班号查询

在「航班查询」页面选择「航班号查询」标签，输入航班号即可同时从 FR24、Google Flights、Airplanes.live 三大数据源并发检索航班信息。

输入格式

航班号由 航空公司代码（2-3位字母/数字） + 数字编号 组成。

# 中国国际航空 CA981（北京→纽约） CA981 # 中国东方航空 MU5110 MU5110 # 四川航空 3U88（注意：航空公司代码可以字母+数字） 3U88 # 全日空 NH NH859

返回信息

查询结果包含：航班号、航空公司、出发/目的地机场（三字码+城市名）、计划出发/到达时间、航班状态（如延误）、机型、飞行高度/速度、数据来源。

💡 航线中继：如果航班号查询没有价格数据，FlyClaw 会自动根据发现的航线路由，发起第二阶段价格查询（Google Flights + Skiplagged），补充票价信息。

🗺️ 三、按航线搜索

在「航班查询」页面选择「航线搜索」标签，输入出发地和目的地以及出行日期，即可从全部数据源并发搜索航班信息及价格。

基本参数

参数说明示例
出发地 *IATA 代码 / 城市名（中英文）PVG / 上海 / Shanghai
目的地 *同上JFK / 纽约 / New York
出发日期 *YYYY-MM-DD 格式2026-06-15
舱位等级经济舱/超级经济舱/商务舱/头等舱默认 经济舱
货币人民币/美元/保留原始默认 人民币

示例

# 上海 → 纽约，2026年6月15日出生 出发地: 上海 目的地: 纽约 出发日期: 2026-06-15 # 北京 → 东京，商务舱，美元计价 出发地: 北京 目的地: NRT 舱位等级: 商务舱 货币: 美元

🏙️ 四、城市级智能搜索

FlyClaw 内置了 7000+ 机场数据库，支持城市级别的自动展开搜索。输入城市名，会自动覆盖该城市的所有机场。

输入自动展开为
上海 / ShanghaiPVG（浦东）+ SHA（虹桥）
北京 / BeijingPEK（首都）+ PKX（大兴）
纽约 / New YorkJFK + EWR + LGA
伦敦 / LondonLHR + LGW + STN + LTN + LCY
东京 / TokyoNRT（成田）+ HND（羽田）
💡 自动补全：输入出发地/目的地时，系统会提供实时机场建议下拉列表，点击即可选中。
⚠️ 注意：已关闭/货运专用机场会被自动过滤，确保只搜索商业客运航班。

🔄 五、往返搜索

展开「高级选项」，填写 返程日期，即可搜索往返航班，同时获取去程和返程的航班信息及往返总价。

出发地: 上海 目的地: 洛杉矶 出发日期: 2026-06-15 返程日期: 2026-06-25

返回结果中会显示去程航班和返程航班信息。票价显示为「往返含税」完整价格。

🔧 七、配置管理

在「配置管理」页面可以可视化编辑 FlyClaw 的所有设置，无需手动编辑 config.yaml 文件。

六大数据源

数据源说明用途
FlightRadar24全球航班跟踪航班动态、实时位置、状态
Google FlightsGoogle 航班搜索航线搜索、价格查询
Skiplagged隐藏城市票价价格补充、经停航班
飞猪 MCP飞猪开放接口中国国内航班价格
Airplanes.liveADS-B 实时数据航班实时位置追踪
Fast Flights对比验证引擎可选调试用

快捷键

在配置页面按 Ctrl+S 或 ⌘+S 可快速保存配置。

⚠️ 注意：修改配置后需要点击「保存配置」才会写入 config.yaml。点击「恢复默认值」会加载默认配置但不会自动保存，仍需手动保存。

🌐 八、REST API 调用

FlyClaw Web 服务器同时也是一个完整的 REST API 服务，可以通过 HTTP 请求直接调用。

查询航班号

GET /api/query/flight?flight=CA981&date=2026-06-15¤cy=cny

航线搜索

GET /api/search/route?from=上海&to=纽约&date=2026-06-15&cabin=economy&adults=1&stops=0¤cy=cny

完整 API 列表

方法路径说明
GET/api/info服务器状态信息
GET/api/query/flight按航班号查询
GET/api/search/route按航线搜索
GET/api/airports?q=机场模糊搜索
GET/api/airports/resolve?name=机场名称解析
GET/api/config读取配置
POST/api/config保存配置（JSON body）
💡 提示：API 返回 JSON 格式数据，可以直接在代码中解析使用。支持跨域访问。

❓ 九、常见问题

Q: 为什么 Google Flights 没有返回结果？

Google Flights 在中国大陆地区可能访问受限。如果此数据源不可用，FlyClaw 会自动使用其他数据源（FR24、飞猪、Skiplagged、Airplanes.live）进行查询。你可以在配置中关闭 Google Flights 数据源以获得更快的响应速度。

Q: 查询速度慢怎么办？

可以通过以下方式优化：

  • 在配置中减少「全局超时」和「提前返回时间」
  • 关闭不必要的数据源（如 Google Flights、Skiplagged）
  • 设置「优先数据源」，一旦该源有结果立即返回

Q: 输入中文城市名能识别吗？

可以。FlyClaw 内置 7000+ 个机场的中英文名称及别名，支持中文、英文、IATA 三字码混合输入。例如输入 上海 会自动映射到 PVG + SHA。

Q: 价格数据来源是什么？

价格数据来自飞猪（Fliggy MCP）、Google Flights 和 Skiplagged 三个独立数据源。不同来源的价格可能存在差异（含税/不含税、舱位差异等），FlyClaw 默认以人民币（CNY）统一输出并取最低价格。

Q: 需要注册账号或 API Key 吗？

不需要。FlyClaw 基于公开数据源，所有核心功能零 API Key 依赖，开箱即用。

Q: 如何更新机场数据？

机场数据在需要时自动更新（取决于配置中的 airport_update_days）。也可以在配置中设置自定义更新 URL。
